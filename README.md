## v12: Supabaseクラウド同期

Supabaseへのログインと端末間同期を追加しました。

### 接続先
- Project URL: `https://zrihlqlqgpbmtlhigceb.supabase.co`
- Publishable key: アプリ内に設定済み
- Secret / service_role key は使用していません

### ログイン
画面上部の「☁ クラウド」から、Supabase Authenticationに作成した
メールアドレス＋パスワードでログインします。

### 初回同期
- クラウドが空で端末に曲がある → 端末の曲をクラウドへアップロード
- 端末が空でクラウドに曲がある → クラウドから端末へダウンロード
- 両方に曲がある → IDと更新日時を見ながらマージ

### 通常同期
- 曲追加 / 編集 / お気に入り / タグ変更 / 点数追加などをクラウドへ反映
- 削除もクラウドへ反映
- オフライン時の変更は端末に残り、次回同期時に送信
- アプリ起動時（ログイン状態）とオンライン復帰時に自動同期
- 「今すぐ同期」ボタンでも同期可能

### ローカル保存も継続
IndexedDBは端末内キャッシュとして引き続き使用します。
クラウドに問題がある場合でも、端末内データとJSON/CSVバックアップを利用できます。

### セキュリティ
- ブラウザに入っているのは公開前提のPublishable keyだけです
- Supabase RLSでログイン中ユーザー自身のsongsだけ読み書きできます
- Database password / secret key / service_role key はアプリに含めません

## v16 同期安全性・自動化
- アプリ起動時だけでなく、スマホでアプリへ戻った時・PCでウィンドウを再表示した時にも自動同期
- 10秒の間隔制限で不要な連続同期を防止
- 前回同期時のクラウド状態を端末に保持し、3-way mergeで別端末の独立した編集を統合
- メモ等の同一項目を両端末で同時変更した場合は更新日時が新しい側を採用し、競合件数を表示
- タグとDAM/JOYSOUND点数履歴は端末ごとの追加内容を統合
- 削除競合ルールを明確化
  - 自端末で削除後にクラウド側でより新しい編集があれば編集を復元
  - 他端末で削除済みの曲を古い端末が編集していても、原則として削除を優先し誤復活を防止
- 同期結果に ↑送信 / ↓受信 / 削除 / 競合 件数を表示
- JSON書き出し時刻を記録し、最終バックアップ日時を表示
- 30日以上JSONバックアップしていない場合はバックアップ推奨を表示


## v17 曲追加フォーム操作
追加したショートカットは指定されたものだけです。

- テンキー `+`：キーを1上げる
- テンキー `-`：キーを1下げる
- キー未登録時は `+` で `+1`、`-` で `-1`
- キー変更範囲は `-6` ～ `+6`
- `Enter`：曲追加フォームの次の主要項目へ移動
- 日本語IMEの変換確定中のEnterはショートカットとして扱わない
- 連続追加モード中のみ `Insert`：保存して次の曲へ
- 通常追加・編集時の `Insert` には保存動作を追加しない
- 保存ボタンをDAM / JOYSOUND点数入力欄より上へ移動

## v19 複数選択・一括編集
- 曲一覧に「複数選択」モードを追加
- 選択中は曲カードをタップ / クリックして複数曲を選択
- 表示中の曲をまとめて全選択
- 選択解除 / 選択モード終了
- 選択曲へタグを一括追加
- 選択曲から指定タグを一括削除
- お気に入りを一括でON / OFF
- 定番曲を一括でON / OFF
- 練習中を一括でON / OFF
- 選択曲を一括削除
- キーや採点履歴は誤操作防止のため一括変更対象に含めない
- 一括編集した各曲は通常の編集と同様にクラウド同期対象になる
