# Karaoke Manager PWA - v7

## 自動カラオケセッション
点数の登録日時からカラオケ1回分を自動判定します。

- あるセッションの最初の採点を開始時刻とする
- その開始時刻から12時間以内の採点は同じセッション
- 12時間を超えた次の採点から新しいセッション
- 日付をまたいでも12時間以内なら同じセッション
- 手動の「新しいカラオケ」ボタンはなし

既存の点数履歴も recordedAt を使って自動的にセッションへ振り分けます。

## v7で追加・変更した機能

### セッション履歴画面
- カラオケ #1、#2…のように自動表示
- 開始〜最終採点時刻
- そのセッションで歌った曲数 / 採点数
- 曲ごとのDAM / JOYSOUND点数
- 曲を押すと曲詳細へ移動

### 未歌唱回数
「何日前」ではなく「何回のカラオケで歌っていないか」で管理します。

例:
- 最後に歌ったのがカラオケ #7
- 最新がカラオケ #10
- → 3回のカラオケで未歌唱

フィルター:
- 一度も歌っていない
- 1回以上
- 2回以上
- 3回以上
- 5回以上
- 10回以上

並び替え:
- 未歌唱回数が多い順

### 自己ベスト更新表示
DAM / JOYSOUNDそれぞれで点数追加時に過去最高を超えると、
「自己ベスト更新！」を表示します。

### 定番曲
お気に入りとは別に「定番曲」フラグを追加。
- 曲編集でON/OFF
- 定番曲だけ絞り込み可能
- 曲詳細にも表示
- CSV / JSONでも保存

### 練習中
「練習中」フラグを追加。
- 曲編集でON/OFF
- 練習中だけ絞り込み可能
- 曲詳細にも表示
- CSV / JSONでも保存

## v8 UI修正
- ライトモード時、登録曲数パネル・検索/フィルターパネル・バックアップパネルの背景を白に統一
- ダークモードは従来どおり黒系背景


## v9 UI / 並べ替え修正
- 検索・フィルター・並べ替えをまとめて初期状態へ戻す「リセット」ボタンを追加
- リセット後の初期状態:
  - 検索: 空欄
  - フィルター: すべて
  - アーティスト: すべてのアーティスト
  - タグ: すべてのタグ
  - 未歌唱回数: 指定なし
  - 並べ替え 優先度1: 曲名順
  - 並べ替え 優先度2: 指定なし
- 並べ替えを優先度1 / 優先度2の2段階に対応
- 優先度1で同順位になった曲だけ、優先度2で並べ替え


## v10 リセット動作変更
- 「リセット」ボタンの対象から並べ替えを除外
- リセット対象:
  - 検索欄
  - すべて / お気に入り / 定番曲 / 練習中 / キーあり / キーなし
  - アーティスト
  - タグ
  - 未歌唱回数
- 並べ替え 優先度1 / 優先度2は現在の選択を保持
- アプリ初回表示時の並べ替えは従来どおり
  - 優先度1: 曲名順
  - 優先度2: 指定なし
