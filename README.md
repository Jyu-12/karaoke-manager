# Karaoke Manager PWA v39 - 3モード版

## v39 の変更
- モードを「採点モード / 管理モード / 閲覧モード」の3つにしました。
- 採点モード：従来どおり、曲をタップすると点数入力専用画面を開きます。
- 管理モード：曲をタップすると詳細画面を経由せず、すぐ曲編集画面を開きます。
- 閲覧モード：曲をタップすると保存済み情報の詳細画面を開きます。編集・追加・削除・お気に入り変更などはできません。
- 閲覧モードでも検索・絞り込み・並べ替えは使用できます。
- v38までの自動同期、タグ背景色、タグ「含む / 以外」、検索バー固定などは維持しています。

Supabase側の追加SQL設定は不要です。
